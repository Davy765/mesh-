Good to know

What can this model do?

It recognises handwritten digits, 0 to 9. That is all. It is a small network trained on a public set of handwritten digits (MNIST). It is not a chatbot, and it does not read or learn from websites.

Does it learn from my drawing?

No. Your drawing is used to answer you and then thrown away. The model only learns from the training data its agents hold, and every update is voted on by the network before it is used.

Why is it sometimes wrong?

It is small and still learning, and drawings on a screen look a bit different from the scanned handwriting it learned from. Watch the accuracy chart: it improves as training rounds are accepted.

What does "ejected for cheating" mean?

Some nodes may cheat: on the demo network a few do so on purpose (they have "liar", "poisoner" or "cheater" in their names). Spot checks catch servers that return wrong answers, and voting throws out poisoned updates. A caught cheater loses half its stake and is removed from the network.

Mesh is an open-source experiment. Test network tokens are play money. Source on GitHub
